# Tech Stack

- **Runtime**: Node.js
- **Package Manager**: pnpm
- **Language**: TypeScript
- **Framework**: Nuxt 4
- **UI Framework**: Vue 3
- **Router**: Vue Router 4
- **Styling**: Tailwind CSS
- **Color Mode**: `@nuxtjs/color-mode`
- **Data Fetching**: `ofetch` via `useApi().apiFetch(...)`
- **Server Layer**: Nitro server routes for API proxying
- **Icons**: `lucide-vue-next`
- **Validation Libraries Present**: `zod`, `vee-validate`
- **Linting**: ESLint
- **Style Linting**: Stylelint
- **Formatting**: Prettier
- **Type Checking**: `nuxi typecheck`
